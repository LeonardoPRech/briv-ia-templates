# Índice auxiliar dos templates

Usar este modelo no modo completo e ao orientar outra IA a escolher templates. Preencher um registro por arte, distinguindo modelos e adaptações existentes. Não inserir o índice dentro dos frames de arte. Reutilizar registros existentes do fluxo e atualizar somente o escopo autorizado.

## Registro por template

| Campo | Valor observado ou testado |
| --- | --- |
| Identificação estável e localização | Arquivo, página, node ID/link; nome real; modelo e sequência existentes |
| Versão inspecionada | Data e referência do estado avaliado |
| Finalidade | Uso observado; se inferido, identificar a inferência |
| Formato | Tipo e dimensões reais; não deduzir variantes ausentes |
| Blocos de texto | Quantidade, função e identificação de cada bloco; distinguir itens de lista e camadas internas |
| Imagens | Pessoa, fundo, produto ou montagem; presença, localização e independência de substituição |
| Capacidade aproximada observada | Conteúdo atual: linhas por bloco, itens, caracteres se medidos; nunca apresentar como máximo |
| Campos substituíveis | Texto/imagem, localização, agrupamentos que devem permanecer juntos |
| Elementos fixos | Marca, decoração e outras restrições verificadas |
| Comportamento testado | Alteração exata, resultado, evidência e versão; usar “não testado” quando aplicável |
| Limitações | Cortes/colisões verificados, fontes ausentes, texto incorporado, máscaras restantes, dependências |
| Adaptações relacionadas | IDs/links existentes e relação observada; registrar “não identificadas” quando for o caso |
| Referência aprovada e base aplicável | Identificação das referências usadas, sem inventar regras de marca |

## Seleção baseada no índice

1. Identificar finalidade, formato, conteúdo e imagens exigidos pelo pedido.
2. Procurar compatibilidade com os campos documentados e as restrições da base de conhecimento.
3. Comparar candidatos pela adequação dos blocos, independência dos assets e adaptações necessárias.
4. Explicar a indicação com observações concretas. Diferenciar capacidade observada de comportamento testado.
5. Se o conteúdo exceder as condições testadas, validar em uma cópia temporária antes de garantir a adequação. Se não houver candidato comprovadamente compatível, registrar a lacuna.

O índice é um auxílio à seleção. Não permite prometer expansão ilimitada nem generalizar um teste de um modelo para todos os outros.
